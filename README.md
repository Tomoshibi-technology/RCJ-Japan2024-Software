# Japan2024-Software
ロボカップジュニア・ジャパンオープン2024名古屋に出場した際のプログラムです

# コードの見方
主な実装は`RCJ-Japan2024-Software/<ロボット単位のフォルダ>/<マイコン単位のフォルダ>`内の `Core/Inc`にあるヘッダファイルと、`Core/Src`にあるソースファイルです。その他のファイルにはピン割り当て、プロジェクト設定、ビルド関連が含まれます。

# フォルダ構成・役割
- Center : パフォーマンスを統括するPC用プログラム
- LEDPole : LEDPoleロボットの制御プログラム
- MovingDisplay : MovingDisplayロボットの制御プログラム
- RobotArm : RobotArmロボットの制御プログラム
- Twelite : ロボット間の無線通信プログラム
