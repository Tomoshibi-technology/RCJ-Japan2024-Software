# MovingDisplay
MovingDisplayとは自律移動する台車上にLEDディスプレイを搭載し、空間内で移動しながら映像を表示するロボットです。

## コードの見方
主な実装は`MovingDisplay/.../Core/Inc`にあるヘッダファイルと、`Core/Src`にあるソースファイルにあります。その他のファイルにはピン割り当て、プロジェクト設定、ビルド関連が含まれています。
<br> 例）`MovingDisplay/Odometry/Core/Inc/as5600.h`

## フォルダ構成・役割
- `Encoder/`：エンコーダ基板上のマイコンで動作するプログラム。エンコーダ値の取得と速度の算出を行い、結果をモータ基板へ送信する。
- `Mother/` : マザー基板上のマイコンで動作するプログラム。オドメトリ基板から受信した自己位置データをもとに、表示する映像の生成とオムニ4輪台車の制御演算を行う。そして各モーター基板に目標速度を、各LEDパネル基板に映像データを送信する。
- `Motor/` : モーター基板上のマイコンで動作するプログラム。エンコーダー基板から受信した実速度データと、マザー基板から受信した目標速度データをもとに、モーターのフィードバック制御を行う。
- `Odometry/` : オドメトリ基板上のマイコンで動作するプログラム。エンコーダー値の取得と自己位置推定を行い、現在のロボット座標をマザー基板に送信する。
- `Panel/` : LEDパネル基板上のマイコンで動作するプログラム。マザー基板から受信した映像データをピクセル単位のRGB情報に変換、さらにLEDが読み取り可能なPWMに変換して出力する。
